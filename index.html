How breeding works

Target power = floor((A power + B power + 1) / 2). The game picks the Pal whose power is closest to this number. Special pairs override it — certain parent combinations always produce a fixed child regardless of power. A pair is “special” only when it appears in the special-combo list; everything else follows the formula.

The species result is guaranteed — target power is not a success chance. The only percentage shown anywhere is “♂ male rate”.
